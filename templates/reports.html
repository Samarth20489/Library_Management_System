Department Borrowing Statistics (GROUP BY & HAVING)

Concepts: Multi-table JOIN, GROUP BY, HAVING COUNT(*) >= 1
{% for row in dept_stats %} {% endfor %}

SQL Query Executed (Viva Explanation): SELECT s.department, COUNT(DISTINCT s.student_id) AS student_count, COUNT(bi.issue_id) AS total_loans, SUM(CASE WHEN bi.return_date IS NULL THEN 1 ELSE 0 END) AS active_loans FROM Students s LEFT JOIN Book_Issues bi ON s.student_id = bi.student_id GROUP BY s.department HAVING COUNT(DISTINCT s.student_id) >= 1 ORDER BY total_loans DESC;
